# 🐍 Snake Water Gun Game (Python)

A simple Snake–Water–Gun game implemented in Python where the user plays against the computer.

---

## 📌 Game Rules

Snake 🐍 beats Water 💧  
Water 💧 beats Gun 🔫  
Gun 🔫 beats Snake 🐍  
Same choice results in a tie.

---

## 🛠️ Technologies Used

- Python 3
- Random module

---

## 🎮 How to Play

1. Run the Python file
2. Enter your choice:
   - -1 → Snake 🐍
   - 0 → Water 💧
   - 1 → Gun 🔫
3. The computer randomly selects its move
4. The winner is displayed

---

## ▶️ Sample Output

Enter a number (-1, 0, 1): 0  
You chose Water  
Computer chose Gun  
You win!
